# Student Database CRUD Application

## About the Project
This project is a Student Database CRUD Application developed using
Python, FastAPI, and SQLite.

It allows users to create, view, search, update, and delete student
records through REST API endpoints.

## Technologies Used
- Python
- FastAPI
- SQLite
- Pydantic
- Uvicorn

## Features
- Add new student records
- View all students
- View a student by ID
- Search students by name or course
- Update student details
- Delete student records
- Validate email addresses
- Prevent duplicate email addresses

## Student Information
Each student record contains:
- Student ID
- Name
- Date of Birth
- Email
- Phone Number
- Course
